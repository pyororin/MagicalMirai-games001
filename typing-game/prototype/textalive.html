実楽曲の文字単位タイミングで判定エンジンを回す検証機。既定曲はマジカルミライ2025課題曲です。 漢字・記号は打鍵対象外(灰色)で、かなだけを打ちます(読みデータの扱いは本実装の課題)。 歌詞の下に打ち方のヒント、フレーズ内のどこを歌っているかのバーを表示します。

TextAlive から楽曲と歌詞タイミングを読み込んでいます。

検証ポイント: 文字の発声タイミングと打鍵時刻の突き合わせ精度、ズレの体感。 ズレを感じる場合は何 ms ずれるかをリザルトの平均デルタで確認してください(キャリブレーション実装の判断材料)。 アプリトークンは TextAlive の設計上クライアントに埋め込む公開値です。

  • 打鍵音・完了音は Web Audio 合成。曲のコード進行までは追わない近似の音階です(実際の歌のピッチとは一致しません)
  • フリックの濁点は、清音の cross をそのまま使い「斜めスライド」で入力します(旧・みんなの顔文字キーボード方式を参考)。あ段の濁点(が/ざ/だ/ば)は短く離すだけで入力できます
  • 漢字の読み(ひらがな化)は TextAlive から提供されないため既定では打鍵対象外です。未検証の読みを機械的に補うと誤判定の元になるため、確認済みの読みだけをコード内 KANJI_READINGS に追記する運用にしています

合成音版のデモは demo.html。エンジンは src/ と同一設計。
本アプリは TextAlive App API を利用しています。
