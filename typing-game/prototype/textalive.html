TextAlive から楽曲と歌詞タイミングを読み込んでいます。

操作: レーンをタップ / フリック(指を離した瞬間に確定+SE)。PC は Space=タップ、矢印キー=上下左右。
検証ポイント: 文字の発声タイミングと入力時刻の突き合わせ精度。ズレはリザルトの平均デルタで確認できます。 課題曲以外の楽曲は読みデータが無いため、かな表記の文字だけが打鍵対象になります。

合成音版のデモは demo.html。判定コアは src/judge.ts と同一設計。
読みデータは tools/build-readings.mjs(kuromoji)で事前生成し data/readings/ に同梱。
本アプリは TextAlive App API を利用しています。
