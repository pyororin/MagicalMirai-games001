打鍵ミライ

歌詞を、メロディに乗せて打つ。マジカルミライ プロコン応募企画の判定エンジンを、 実際に触って確かめるためのプロトタイプです。楽曲は権利処理不要の自動生成音、 歌詞はオリジナルを使っています。

難易度
SCORE 0 COMBO 0

歌詞を打つ準備はいい?

曲が流れます。光っている文字を打ってください。発声のタイミングちょうどで打てば JUST。 先に打ち貯めても構いません — その分は TYPED として受け付けます。

かな確定で判定する

「し」は shi でも si でも打てます。判定はかなが確定した瞬間にだけ走るので、 打鍵数が2でも3でもリズム上は等価です。日本語タイピングとリズムゲームを両立させる要です。

先に打ち貯められる

発声を待たずに先行入力できます。速い箇所を打ち貯めれば曲に置いていかれません。 ただし点は伸びない — リズムに乗せた JUST は倍の価値があります。

難易度で密度が変わる

EASY と NORMAL は打鍵対象の文字を間引きます。灰色の文字は打たなくて構いません。 HARD は全文字。等速で打ち切れるか試してみてください。

スマホはフリックで

フリック入力は1かな=1操作なので、実はローマ字よりリズムに乗れます。 キーを押した指を上下左右に払って母音を選びます。

これは判定エンジンの検証機です。 本番は TextAlive App API から課題曲の文字単位タイミングを取得して同じ判定を回します。 ここでは API に接続できないため、タイミングデータを自前で生成しています。 音は Web Audio で合成した簡易的なもので、実際のボカロ曲ではありません。

ローマ字テーブル・判定ロジックはリポジトリの prototype/src と同一の設計です。
