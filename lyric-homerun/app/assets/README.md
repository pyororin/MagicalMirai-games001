# 絵の差し替え

ここの画像は、`tools/artgen` がコードで描いた元絵を、`tools/img2vector` で手書き風にしたものです(作り方は `../../art-src/README.md`)。コードの仮の絵に戻すときは `art.json` を空にします。画像を置いて `../data/art.json` にパスを書くと差し替わります
(空文字のままなら仮の絵で描きます)。

```json
{ "background": "assets/bg.png", "batter": "assets/miku.png", "pitcher": "assets/pitcher.png" }
```

| キー | 内容 | 目安 | 合わせる位置 |
| --- | --- | --- | --- |
| background | 球場の背景(縦長) | 1080×2100 前後。画面全体に cover で敷く | 投手の足元 = 上から 40%、ホーム = 上から 70%、左右は中央 |
| batter | 打者(ミク・斜め後ろ姿・ネギは含めない) | 透過 PNG、高さ 600px 前後 | 画像の下端中央 = 足元。ネギはコードが手元から描く |
| pitcher | 投手(ミク以外) | 透過 PNG、高さ 400px 前後 | 画像の下端中央 = 足元 |

## 素材のルール(必ず確認)

`docs/PRINCIPLES.md` のとおり、マジカルミライ プログラミング・コンテストの規約は
**作品に表示される絵・音・文章に AI 生成物を使うことを一切認めていません**(コードの AI 支援は可)。
応募する版に入れる画像は、人が描いたもの、または正規に許諾を得たものに限ります。
二次創作として登場させられるのはピアプロキャラクターズだけです。

## 打者の手元(右打ち)

`art.json` の `batterHand` に、打者画像の中の拳の位置を `[左からの比率, 上からの比率]` で書くと、ネギがそこから出る。
未指定なら仮の位置から出る。デザイン基本設計(Artifact)の §3 を参照。

## 出どころ(必須)

ここに置く画像は、すべて `../../art-src/provenance.json` に出どころを書く。`python tools/check_art_provenance.py` が通らない素材は応募版に入れない。
画像生成 AI の出力(元絵に使ったものを含む)は使えない。
