# ミクの本体はツインテールである

初音ミク「マジカルミライ」プログラミング・コンテスト応募企画（案）。

黄色いタイヤのホイールに緑のホースを巻き付けるとミクに見える——
「ミクっぽさ」は少数の記号（ツインテール・青緑・シルエット）に宿る、という観察をゲームにします。

**リズムに合わせて、日常のものにツインテールを生やす**ゲームです。
四拍子なら 2 拍目で髪留めをタップし、お題の髪型どおりに伸ばして 4 拍目で髪を生やす。
左右そろうと**ミク度**が判定され、そのミクが背景に並んでいきます。
曲が終わるころには、画面が**ミクだらけ**になっています。

ただの視覚ギャグ（出落ち）で終わらせないための核は 2 つ:

> **1. 譜面は曲そのもの。** 拍・小節・歌詞・尺はすべて TextAlive App API の実データ。
> 曲が変われば譜面も尺も難度も変わる。作り込んだ譜面データは 1 つも持たない。
>
> **2. 「どちら側か」は耳でしか分からない。** 髪留めの合図音は付ける側にステレオ定位する。
> 目で見て打つことはできず、左右を取り違えるとミク度が大きく下がる。

## 遊ぶ（公開デモ）

- **実曲版（本命 / TextAlive 接続）**: https://pyororin.github.io/MagicalMirai-games001/miku-twintail/
  - `?song=0`〜`?song=5` で課題曲を直接指定できます
  - `?diff=easy` / `normal` / `hard` で難易度を指定できます
- **擬似曲版（通信・トークン不要）**: https://pyororin.github.io/MagicalMirai-games001/miku-twintail/mock.html
  - `?bars=8&bpm=100&diff=hard` で尺・テンポ・難易度を変えられます

### 遊び方

飛んでくるものが 2 種類あり、**何が来るかで叩く拍が変わります**。

| 飛んでくるもの | 叩く拍 | すること | できる髪 |
| --- | --- | --- | --- |
| **□ 髪留め** | 小節の最後の 1 拍前（四拍子なら 3 拍目） | タップして、**最後の拍まで指でなぞる** | **なぞった線がそのまま髪の形になる** |
| **〜 髪** | 小節の最後の拍（四拍子なら 4 拍目） | **タップするだけ** | お題の髪型どおりの綺麗な髪 |

- **叩く拍の音だけが左右にパン**します。耳だけで「どちら側の・どの拍か」が分かります（ヘッドホン推奨）
- 外すと**ネギ**が斜め上に生えます。左右を取り違えるとミク度が大きく下がります
- **一時停止**できます。停止中に「再開」「メニューへ戻る」を選べます
- **音量つまみ**が 2 本あります。**楽曲**と**拍・効果音**を別々に絞れます
  （拍が楽曲に埋もれるときは楽曲を下げてください）。値はブラウザに保存されます
- **サビ**では髪型がロング寄りになり、体が完成した次の拍に**決めポーズ**（床の輪）が出ます
- 効果音の音程はその瞬間のコードに乗るので、合いの手が曲から外れません

## ミク度 — 判定条件（仕様）

完成した 1 体につき **0〜100 の整数**で決まります。
**リズム 36 点・造形 64 点**。難易度を変えてもこの定義は動きません
（変わるのは判定窓とガイドの出し方だけなので、難易度をまたいでも同じ物差しで比べられます）。

### 加点（合計 100）

| 記号 | 指標 | 満点 | 内訳と式 |
| --- | --- | --- | --- |
| **R** | リズム | **36** | 房ごと 18。PERFECT 18 / GOOD 11 / OK 4 / ネギ 0 |
| **A** | 角度 | **18** | 房ごと 9。`9 × clamp01(1 − err / 0.35)`<br>err = 房の向きとお題の髪型の目標角との差[rad]。0.35rad ≒ 20° ずれでゼロ |
| **T** | ツインテールらしさ | **16** | 房ごと 8。**房の形そのもの**を見る<br>素直さ `4 × clamp01((reach − 0.55) / 0.20)`<br>　reach = 毛先までの直線距離 ÷ 弧長。巻き込み・折り返し・往復はここで落ちる<br>垂れ `4 × clamp01((descent − 0.45) / 0.40)`<br>　descent = 下へ向かっている区間の割合。上へ跳ね上げた房はここで落ちる |
| **P** | つけ位置 | **12** | 房ごと 6。正しい側 `4 × clamp01((外向き度 + 0.02) / 0.30)`<br>根元の高さ `2 × clamp01(1 − \|h − 0.88\| / 0.7)`（h: 1 = お題の上端, 0 = 中央） |
| **S** | 左右の対称 | **10** | 鏡映角の一致 `5 × clamp01(1 − Δθ / 0.55)`<br>長さの一致 `5 × clamp01(1 − \|ℓL − ℓR\| ÷ max(ℓL, ℓR) ÷ 0.45)`<br>**両房とも髪で、左右を取り違えていないとき**のみ |
| **L** | 長さ | **8** | `8 × clamp01(1 − \|平均房長 ÷ 目標長 − 1\| / 0.55)`<br>目標長 = 髪型の `len` × お題の大きさ。短すぎても長すぎても下がる |

### 減点

| 記号 | 条件 | 減点 |
| --- | --- | --- |
| **X** | 左右取り違え（その側と反対側に髪留めを置いた） | **−12 / 房**。加えてその房の側点 4 を失い、1 本でもあれば **S = 0** |

```
ミク度 = clamp(R + A + T + P + S + L − X, 0, 100)
```

ネギ（失敗）の房は R/A/T/P すべて 0 になり、S・L も成立しません。
**片方でもネギならミク度は最大 45**、**両方取り違えると最大 52** です。

| ミク度 | 掛け声 | 称号 | 背景での光り方 |

| 80〜92 | 「ミク！」 | ほぼミク | **淡く光る** |

## 構成 — 擬似曲版と実曲版で同じゲーム本体を使う

```
app/src/game/     ゲーム本体
  stages.js         ステージ 4 種 × お題 24 種（背景と描画）
  score.js          ミク度の定義（純関数。Node からも検証できる）
  hair.js           髪の形（なぞった軌跡／理想曲線）と描画・形の計測
  audio.js          拍の音・効果音・掛け声（Web Speech）
  core.js           状態機械と描画ループ
app/src/song/     ソングアダプタ（楽曲へ触る唯一の口）
  mock.js           擬似曲（130BPM を自前合成）
  textalive.js      実曲（TextAlive App API）
app/index.html    実曲版      app/mock.html  擬似曲版
prototype/        v1（自由描画版）の参考モック
```

`core.js` は楽曲をアダプタ越しにしか触りません
（契約は `ready / time / atAudio / beat / bar / barIndexAt / onBeat / charAt / vocalAt / ended`）。
モックで詰めた手触りが、そのまま実曲版の手触りになります。

## 開発

```sh
cd miku-twintail/app
npm ci
npm run dev        # http://localhost:5173/           実曲版
                   # http://localhost:5173/mock.html  擬似曲版
npm run build      # dist/ に両ページを出力
```

ホスト接続（TextAlive App Debugger）での確認は [docs/TEXTALIVE_DEV.md](docs/TEXTALIVE_DEV.md) §3 を参照。

## クレジット

楽曲情報・歌詞の解析データは [TextAlive App API](https://developer.textalive.jp/)（産業技術総合研究所）と
[Songle](https://songle.jp/) を利用しています。楽曲の著作権は各権利者に帰属します。
「ミク！」の掛け声はブラウザの音声合成（Web Speech API）によるもので、
**初音ミクの音声素材は使用していません**。
