# 調査: くまのプーさんのホームランダービー!

Yahoo!きっず(ディズニー)で配信されていた Flash ブラウザゲーム。リズム/タイミング系ゲームの先行事例として整理する。
取得日 2026-11-22。**読めた出典と未確認事項を分けて書く**(推測は書かない)。

## 1. 概要
- Flash 製の無料ブラウザ野球ゲーム。プーさんがバッター。マウスでバットを動かし、クリックで振る。
- ボールが画面外に消えたらホームラン。各投手との対戦で**一定本数のホームランを打てばクリア**(ノルマ達成後は以降の見逃しがあってもクリア)。
- 子ども向けの見た目に反して**極端に難しい**ことで有名。

## 2. 構成(全8ステージ)
| # | 投手 | 特徴 |
| --- | --- | --- |
| 1 | イーヨー | 比較的やさしい |
| 2 | ランピー | やや速い。左右に投げ分け |
| 3 | ピグレット | 投げ分け+速球 |
| 4 | カンガ&ルー | 縦にバウンドする球 |
| 5 | ラビット | ゆっくり→急加速 |
| 6 | オウル | 横にジグザグ変化 |
| 7 | ティガー | 消える魔球 |
| 8 | クリストファー・ロビン | 7匹の球がランダムに混ざる。50球、打率8割が必要とされる |

- 成長要素: ポイントでスピード/ミート/パワーを強化(推奨はスピード>パワー>ミート)。ロビン戦の前にカンストさせる攻略がある。
- 未確認: ステージごとのノルマ本数、ハチミツ要素、BGM・効果音・判定の内部仕様。

## 3. 難しさの正体(攻略記事・評論から)
- 球種が**ステージごとに「読みの種類」を変える**(速度変化・消失・ジグザグ・バウンド)。
- クリックは一瞬だと反応しにくく、**長めに押す**ほうが当たる(入力の確定点が曖昧=理不尽に感じる要因)。
- バットの影を立ち位置の目印にする、芝から土に変わる位置を振りどきにするなど、**視覚的な目印を自分で探す**ゲーム。
- 評価: Eurogamer(2013)「深くないが中毒性」/ PCGamesN(2013)「物理と公平性を無視」/ Kotaku(2013)「子ども向けには難しすぎ」/ Complex(2013)「最難ブラウザゲームの一つ」。QWOP と比較された。

## 4. 歴史
- 2007年 Walt Disney Japan 開発、DisneyGames.jp で公開(遅くとも 2007-12-20)。
- 2008年 Yahoo!きっずで配信。英語版は disney.com。
- 2012年1月頃 2ちゃんねるで話題化。プーさん=「プニキ」、ロビン=「ロビカス」。2013年1月頃に 4chan/Reddit で拡散。「ハランデイイ」はこのネタへの拒否反応を示す語と説明される(語源は不明)。
- 2020-12-16 16時 Flash 終了に伴い配信終了(2019-07 に予告)。
- 2023-11-26 ソウルの KBO チャリティマッチで選手がプーさんの着ぐるみで打席に立ち「リアルホームランダービー」として再燃。

## 5. 保存・復活
- Internet Archive に保存: 英語版 `archive.org/details/homerunderby_en`、日本語版 `archive.org/details/homerun_20201126`(Ruffle 組み込み済み。初回読み込みは長い)。

## 6. 本リポジトリへの示唆(仮説。企画化の前に検証)
- 「1本のバットスイングだけ」の単純操作 + **ステージごとに読みが変わる球種**で長く遊ばせる構造は、リリックアプリの曲展開(Aメロ/サビ)とも相性が良い。
- 難しさが「理不尽」と「中毒性」の両方で語られている。**判定窓と失敗の見せ方**が肝(`ontology/rhythm-game.yaml` 参照)。
- 本作のキャラ・画像・音は**流用しない**(権利と `docs/PRINCIPLES.md` の素材ルール)。参考にするのはゲーム構造のみ。
