# キャラクターのバランス — デッサンとデザインの基本(調査と検査項目)

調査日 2026-11-23。キャラクターの絵(コードで描いた元絵)が「整っているか」を、感覚でなく**測って**確かめるための基準。
資料どうしで食い違う数値は、1点でなく**幅**で持つ。検査は `tools/artgen/proportion_check.py`(使い方は `tools/artgen/README.md`)。

## 1. 調べて分かったこと

出典(読んだのは検索結果の要約。原典の図は確認していない):

- Clip Studio Tips「[Body Proportion in Chibi Drawing](https://tips.clip-studio.com/ja-jp/articles/4829)」「[General Tips on Chibi Art](https://tips.clip-studio.com/ja-jp/articles/4897)」/ [Easy Steps to Creating Chibi Characters](https://www.clipstudio.net/how-to-draw/archives/155423)
- 人体の比率(日本語): [asahi-net 人体の全身比率](https://www.asahi-net.or.jp/~zm5s-nkmr/hitoFiles/zenshin1.html)
- [Fiveable: Essential human figure proportions](https://fiveable.me/lists/essential-human-figure-proportions) / [Adobe: how to draw people](https://www.adobe.com/creativecloud/illustration/discover/how-to-draw-people.html) / [Body proportion](https://www.wikiwand.com/en/articles/Body_proportion)
- アニメの顔: [Envato Tuts+: How to Draw Anime Heads and Faces](https://design.tutsplus.com/tutorials/how-to-draw-anime-heads-and-faces--cms-31884)

分かったこと(資料が一致する点 / 割れる点):

| 項目 | 内容 | 一致 |
| --- | --- | --- |
| 頭身 | 頭の高さを 1 として全身を数える(標準は約 7〜8 頭身)。ちびキャラは 2〜3 頭身、低いほど頭・目・髪が大きく丸く、体は省略される | 一致 |
| 目の高さ | 頭頂とあごの**中ほど**。初心者は高く置きがち。ちびキャラは少し**下げる**と丸く幼く見える(下げすぎると驚いた顔になる) | 一致 |
| 目の幅 | 顔の幅は目 5 個ぶん(目と目のあいだ = 目 1 個)。アニメでは崩してよい | 一致(崩してよい) |
| 肩幅 | 頭の幅の約 2〜3 倍(男性 3、女性 2.5 という資料も)。横向きでは厚みだけが見える | 幅あり |
| 肘 | 自然に下ろしたとき、ウエスト(胴のいちばん細い所)の高さ | 一致 |
| 手首 | 股の高さ、または太ももの中ほど(資料で割れる)。指先は太ももの中ほど | **割れる** |
| 腕の内訳 | 肩から手までを 12 に分けると、上腕 5・前腕 4・手 3 | 一致 |
| 膝 | 股から足裏までの**中ほど** | 一致 |
| 脚の長さ | 全身の約半分(股が全身の中ほど) | 一致 |
| 手の大きさ | 顔の大きさ(あごから髪の生え際)ほど。ちびキャラは省略・小さめ | 一致 |
| 足の長さ | 頭の高さほど。ちびキャラは省略 | 一致 |
| 骨格 | 肩のラインを引き、その下に胴の箱、胸と骨盤を別の塊(ハート形)で捉える。胸と骨盤は反対にひねる(コントラポスト) | 一致 |
| 重心 | 立ち姿は、重心から下ろした線(プラムライン)が、足の支え(両足の外側のあいだ)に落ちる。これが外れると倒れそうに見える | 一般原則 |
| シルエット | 黒く塗りつぶしても、何のキャラか分かる。単純で読みやすい形ほど遠くから読める | 一致 |

## 2. このリポジトリの基準(検査する項目)

キャラクターごとに「頭身の幅」「向き(正面/横)」「種類(ちび/アニメ)」を、デザインデータの `style` に宣言する。
検査は、デザインデータの**目印(landmarks)**から測る(目印は、絵の上の位置と合っているかも検査する)。

| 検査 | 内容(アニメ調 / ちび調) | 向き |
| --- | --- | --- |
| P1 頭身 | 頭頂〜足裏 ÷ 頭の高さ が、宣言した幅に入る(ミク 4.0〜5.2、MEIKO 3.0〜4.0) | 全部 |
| P2 目の高さ | 頭頂〜あごの 0.50〜0.66(アニメ)/ 0.55〜0.72(ちび) | 全部 |
| P3 肩幅 | 肩幅 ÷ 頭の幅 が 1.0〜2.0(正面)。横向きは胴の厚み ÷ 頭の幅 が 0.45 以上 | 向きで切替 |
| P4 脚の長さ | 股〜足裏 ÷ 全身 が 0.38〜0.50(アニメ)/ 0.30〜0.42(ちび) | 全部 |
| P5 膝の位置 | 膝が、股〜足首の 0.40〜0.62 の高さにある | 全部 |
| P6 腕 | 上腕 : 前腕 が 0.85〜1.45。にぎりこぶしの直径が、頭の高さの 0.30〜0.60 | 全部 |
| P7 足 | 足(ブーツ)の長さが、頭の高さの 0.50〜1.05 | 全部 |
| P8 脚の左右 | 左右の脚の長さの差が 12% 以内(片脚を上げる等の姿勢は宣言して除外) | 全部 |
| P9 重心 | 胴の重心の x が、両足の外側のあいだの 10%〜90% に入る(プラムライン) | 全部 |
| P10 髪の量 | 髪(ツインテール)がシルエットに占める割合が上限以内(ミク 0.58 まで) | 任意 |
| P11 目印の整合 | 目印が、絵の上の正しい色(目=濃色、拳=肌色、足裏=ブーツの下端)の上にある | 全部 |

この表の数値は、デザインを変えたら**先に Artifact(設計書)を直し**、そのあと検査の宣言を直す。
