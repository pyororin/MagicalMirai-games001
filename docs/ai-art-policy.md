# AI 生成物の扱い — 規約の確認と、クリアする方法の検討

状態: 検討中(2026-11-22)。決めたことは末尾の「決定」に書く。
出典: 公式「応募のきまり」(https://magicalmirai.com/2026/procon/ の `#rule_text` と FAQ)。**2026年版・募集は 2026-06-29 に終了済み**。
2027年版の募集が出たら、必ず原文と突き合わせて更新する(`PRINCIPLES.md` と同じ運用)。

## 1. 規約(原文の要点)

| 区分 | 内容 |
| --- | --- |
| 可 | AI を使った **コード**の生成・補完・バグ修正・リファクタリングなど、コード作成の支援 |
| 不可 | プログラムの出力として**表示される音楽・絵画・文章などの著作物に AI 生成物を使うこと**(「一切認められません」) |
| 例外(可) | 文章の**翻訳**に AI を使うこと |
| 可 | **ユーザーが AI 生成物を動的に作る機能**を実装すること(「AI で生成された作品の利用ではない」) |
| 画像 | 二次創作は**ピアプロキャラクターズのみ**。それ以外も含め、画像は「自分で制作したもの」か「正規に利用許諾を受けたもの」。権利面の保証を主催者にする。許諾作品は作者名をアプリ内に明示 |
| 効果音 | 同上(自作か正規許諾)。対象楽曲の一部と誤認させる使い方は避ける |
| 全体 | プログラムは原則、応募者が独自に考案・開発し、権利を保有するもの。第三者の権利は事前に処理し保証する |
| 凍結 | 募集終了から入賞発表まで、プログラムとソース(**画像などのアセットを含む**)を更新しない。違反は審査対象外 |
| 公開 | 募集期間中は内容を推測させる公開(詳細説明・デモ動画など)を禁止。終了後は「応募作品」と明記すれば可 |

## 2. このリポジトリで起きていること

- `lyric-homerun/` は build 1 を Pages で公開中。今は**コードで描いた仮の絵**。
- Gemini で作った案(背景・ミク・投手)は **AI 生成物**。入れた版は、そのままでは応募できない。
  承認前なので `lyric-homerun/app/assets/` にはまだ置いていない。

## 3. クリアする方法の候補

| 案 | 内容 | 規約上 | 備考 |
| --- | --- | --- | --- |
| A. 人が描く | 本人が描く、または描ける人に依頼/許諾を得て、作者名をアプリ内に明示 | 安全 | 一番確実。工数と調整が要る |
| B. コードで描く | JSON と描画コードで絵を作る(`bunyutto-miku` の `miku-face.json` 方式) | **要確認** | コードの AI 支援は可。ただし AI が考案した図案を AI のコードで描いた絵が「AI 生成物」に当たるか、規約は触れていない。心配なら主催者に質問する |
| C. AI 案を下絵にして人が描き直す | Gemini の絵を参考に、本人が描いてトレースせず作り直す | **グレー** | 「AI 生成物を利用」に当たる恐れ。主催者に質問してから |
| D. 開発用だけに使う | AI 画像は手元のモック確認専用にし、応募版には入れない(`art.json` を空に戻す) | 安全 | 画像の差し替え設計(`art.json`)をそのまま使える |
| E. 実行時にユーザーが生成 | 画面上でユーザーが AI 画像を作る機能 | 可(明記あり) | 静的アプリのみの制約と API キーの扱いが難しく、現実的でない |

## 4. 進め方の提案

1. 絵の方針を A / B / D から決める。B と C は先に主催者へ質問する(問い合わせ先は応募のきまり末尾)。
2. どの案でも、応募用リポジトリには AI 生成画像を入れない(履歴にも残さない)。
3. 凍結ルールがあるので、**絵の差し替えは募集終了より前に済ませる**。
4. 募集期間中の Pages 公開は「内容を推測させる公開」に当たりうる。2027年の本番では公開範囲を見直す。

## 決定

- 2026-11-22(のちに更新): **画像はすべてプログラムで作る。AI 生成の画像は、完成品にも元絵(入力)にも使わない**(ユーザー判断・絶対)。
  元絵にしてよいのは、人が描いた絵、コードやデータで描いた図、正規に許諾を得た絵(作者名を明示)だけ。
  出どころは `lyric-homerun/art-src/provenance.json` に書き、`python tools/check_art_provenance.py` で検査する(AI 由来があると失敗)。
  build 2・3 の背景・ミク・MEIKO は、元絵が Gemini の生成画像でこの基準を満たさなかった。**build 4 で、コードで描いた元絵(`tools/artgen`)から作った素材に置き換えた**(provenance.json はすべて `program`、検査 OK)。過去のコミットには旧素材が残るので、応募用のリポジトリには持ち込まない。
- 2026-11-22: 絵は **B(プログラムによる模写)** の方向で進める。主催者への質問は不要とする(ユーザー判断)。
  元絵を入力として、`tools/img2vector/` で「べた塗り+輪郭」のベクター画像に変換する。
  - build 2 のデモ画像(背景・ミク・MEIKO)は、Gemini で作った元絵からこのツールで作った。**元絵が AI 生成物なので、
    規約上の扱いは未解決のまま**(ツールの出力は元絵の見た目を写すだけ)。応募版に入れるかは別途決める。
  - 投手は MEIKO。
