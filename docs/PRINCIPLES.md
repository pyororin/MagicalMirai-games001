# 大方針 — このリポジトリのゲームが必ず満たすこと

マジカルミライ プログラミング・コンテストの趣旨と応募のきまりから導いた、**全企画共通の前提**。
新しい企画を始める前、設計を変えるときに必ず確認する。企画固有の設計は各企画の `docs/` へ。

## 1. リリックアプリとは何か(目的)

- **リリックアプリ = 楽曲に合わせて歌詞などの映像演出が動く Web アプリ**。TextAlive App API(産総研が研究開発する JavaScript ライブラリ)で作る。
- 従来のリリックビデオは毎回同じ内容を見せるだけで、視聴者は受動的。リリックアプリは**ユーザーの操作で歌詞の見せ方が再生のたびに変わる**ことを狙う。
- コンテストの目的は、プログラミングを通じて**創作文化を体験してもらい、未来の創作文化を予感させる表現を集めること**。
- → このリポジトリのゲームは「ゲームの中に曲を使う」のではなく、**「歌詞・曲のタイミングが遊びの核になっているリリックアプリ」**でなければならない。

## 2. 審査基準(設計判断の物差し)

1. **クリエイティビティ** — 演出が楽曲と**同期して**魅力的に見えるか
2. **イノベーション** — アイデアがユニークで、未来の創作文化を予感させるか
3. **完成度** — 一般的なブラウザ(応募者が意図した環境)で正常に動くか、実装が技術的に優れているか

入選後は一般投票(ミクナビ)があり、プレイして楽しいかも最終的に効く。

## 3. 必須要件(破ると失格/対象外)

| 項目 | 内容 |
| --- | --- |
| API | **TextAlive App API を使う**こと。対象楽曲は毎年の楽曲コンテスト受賞6曲(1曲だけでも可、選曲は審査に影響しない) |
| 静的アプリのみ | HTTP サーバに置くだけで動くこと。PHP/Ruby/Node.js 等の動的サーバは不可 |
| ソース審査 | ソースコードも審査対象。**難読化など理解を妨げる処理は禁止**。ビルドが要るなら Webpack/Vite 等のスクリプトを含める |
| オリジナル | プログラムはオリジナル。企業業務の成果物の流用は不可 |
| 画像 | 二次創作は**ピアプロキャラクターズのみ**可。他は自作か正規許諾のものに限り、許諾作品は作者名をアプリ内に明示。公式サイト/SNSのイラスト・ロゴは提供されない |
| 効果音 | 自作か正規許諾のみ。対象楽曲の一部と誤認させる使い方は控える |
| **AI 生成物** | コード生成・補完・修正などの AI 支援は可。**作品に表示/再生される音楽・絵・文章に AI 生成物を使うことは一切不可**(翻訳は可) |
| 提出 | GitHub プライベートリポジトリを `magicalmirai-procon` に共有 → 応募フォームに URL |
| 凍結 | 2026年版は募集終了時点から入賞発表まで、ソースもアセットも一切更新しない(2025年版は応募完了時点から) |
| 公開 | 募集期間中は内容を推測させる公開(詳細説明・デモ動画等)を禁止。終了後は「マジカルミライ20XX プログラミング・コンテスト応募作品」と明記して公開可 |
| 権利 | 知財は応募者に帰属。ただし**入賞作は主催者が無期限・自由に利用(改変含む)でき、第三者に許諾できる**権利を許諾する |
| 誤認防止 | 主催者が関与したと誤認させる表示は禁止 |

## 4. 技術上の前提(開発者規約より)

- アプリトークンが必要(開発者登録で取得)。クライアント埋め込み前提の公開トークン。
- 動作確認は TextAlive App Customizer(HTTPS 必須。ローカル HTTP は読めない)。
- アプリで扱える楽曲・歌詞は「利用可能コンテンツ」(権利者が許諾したもの)に限る。ユーザ利用規約を分かりやすい場所に表示する義務がある。商用利用は事前相談。
- 開発者規約 PDF の全文は取得できていない(未確認)。応募前に原文を確認すること。

## 5. このリポジトリでの運用ルールへの落とし込み

- ゲームの入力・成否・演出は**曲のビート/歌詞タイミングに紐づける**。曲と無関係に成立するゲームにしない。
- **サーバ不要・静的ファイルのみ**。外部 API 依存は TextAlive 以外を増やさない。
- **ビルド成果物を難読化しない**。ソースは読める形で置く。
- **画像・SE・BGM に AI 生成物を使わない**(コード支援は可)。ミクの描画はコード/JSON で自作する(`bunyutto-miku` の `miku-face.json` 方式)。キャラクターはピアプロキャラクターズの範囲で。
- 第三者素材を使うなら、権利と作者名の明示をアプリ内に入れる。
- 「ミクが関与した公式作品」に見える表記をしない。応募作品である旨を明記する。
- PC・タブレット・スマホのうち**意図した環境**を各企画の設計書に明記し、そこで確実に動かす(完成度の審査基準)。
- 募集期間中の公開(Pages など)は「内容を推測させる行為」に当たりうる。**本番の募集が始まったら、公開範囲と公開物を規約に照らして見直す**。
